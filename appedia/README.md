# KANKURO Appedia

Open [index.html](index.html) directly in a browser; no server is needed.
This snapshot describes the application through roadmap step 6. The generated
model includes independent application contracts, presentation models and the
selected-session center.

The center flows explain authored reports across activations, subscribe-before-read,
workspace Git/directory fallback, bounded inspection, recovery and cancellation.
The old `flow-preview` URL remains available for incoming links and opens the
report center flow.

The Tests tab distinguishes inspected source assertions and recorded execution
from unassessed behavior. Historical coverage and terminal captures retain their
original provenance; they are not measurements of the current implementation.
The complete live resize/relaunch/recovery journey remains unassessed.

## Updating the snapshot

Edit `data/content.js` for roles, flows, rules, tasks and assessments. Extracted
models, diagrams and `data/content-index.json` are generated by the Appedia tooling.
A refresh should validate source references and browser routes, preserve execution
provenance and keep changed-source assessments separate from historical results.
Raw verification reports, evidence inputs and maintenance records are workflow
artifacts kept separately from this browsable snapshot.

Native model E2E runs require the provider/model and total token budget described
in [tests/e2e/AGENTS.md](../tests/e2e/AGENTS.md). Source extraction and browser
checks do not establish terminal E2E behavior.
